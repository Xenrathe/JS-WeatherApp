# README

## WeatherScryer, a medieval-themed daily weather app

![Screenshot of current weather forecast](https://github.com/Xenrathe/JS-WeatherApp/blob/main/Current.png?raw=true)

WeatherScryer is a simple weather-app that allows searching for a location to find the current, hourly (next 24h), and weekly (next 7 days) weather forecast.

Weather Scryer is active on GitHub pages: (https://xenrathe.github.io/JS-WeatherApp/)

### Features:

- Fully responsive layout for mobile, tablet, desktop
- Medieval manuscript themed iconography
- Weather data pulled from visualCrossing.com (note: I'm aware API key is exposed - it's free)
- Uses async / Promise API functionality for API calls

### Tech Stack:

- CSS: Vanilla
- JS: Vanilla
- Backend: N/A - no backend

![Screenshot of weekly weather forecast, on a mobile screen](https://github.com/Xenrathe/JS-WeatherApp/blob/main/Weekly.png?raw=true)
